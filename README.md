# 朝食やさいチャレンジ・保護者版

公開アプリ: https://naoki6043.github.io/yasai-challenge-parents/

元の `naoki6043/yasai-challenge` を履歴付きでコピーした保護者向けアプリです。
元リポジトリ・元管理シート・元Apps Scriptは変更していません。

## アプリ

- ホームの野菜10種類、各3料理の配置と順番、完成写真・工程写真・詳細情報を維持。
- 学ぶ・クイズ・学年選択、利用者の写真登録機能なし。
- 野菜名の枠内に栄養学的特徴を1文表示。
- 同一料理・同一日でも、日付／調理参加3択／摂取量5択を何度でも記録。
- 料理別・全体の履歴、月・料理による絞り込み、編集、個別削除。

## レシピと栄養文の更新

保護者版管理シート:
https://docs.google.com/spreadsheets/d/1mvyWp_CxPcO4_QRbY8bqiXoEWW5XxMpp9ApaH4XdzvM/edit

「レシピ入力」は元と同じ構造です。「公開状態」が「公開」のR01〜R30を取得します。
「野菜情報」は1野菜1行です。C列「栄養学的特徴」を編集し、アプリを再読み込みすると反映されます。
材料、写真、栄養値等の既存の列はそのまま使えます。

アプリは最初に `content.json` の保存済みデータを表示し、保護者版専用APIから最新のシート内容を取得します。
通信できないときは保存済みデータを使います。フォーム入力中の更新で入力内容を消さないようにしています。
元アプリや元のシートを編集しても、保護者版には自動反映しません。

## 記録の連携

記録は利用端末のlocalStorageに保存し、保護者版専用APIへ送信します。
通常の受信先はコピーした管理シート内の「保護者記録」です。最初の受信時に自動作成します。
「設定」で送信待ち件数を確認し、再送できます。通信できない記録は再読み込み・オンライン復帰時にも再送します。

イベントIDで再送を識別し、参加者IDと記録IDの組み合わせで編集・削除を反映します。
古い変更が届いても新しい状態を上書きしません。返されたイベントIDが一致するまでは端末の送信待ちを解除しません。
削除済みの行は、古い再送による復活を防ぐため「削除済み」の状態で保持します。
利用画面では削除され、公開APIから記録を読み出す機能はありません。

端末間で履歴を共有・復元する機能はありません。ブラウザの保存データを消すと、その端末の履歴は失われます。
元アプリの `awveg-v6-` 保存領域と研究用APIは使わず、`yasai-parents-v1-` で分離しています。

## Apps Script

保護者版専用プロジェクト:
https://script.google.com/u/0/home/projects/1GpN-sUiuGoNcucuJNZqXkJZsOu6R9yaAlbInZLr47GoIufo38BhljjWF/edit

`GoogleAppsScript_保護者版API.gs` の内容を、このコピー側プロジェクトの「行動ログ.gs」に設置しています。
ウェブアプリのバージョン1を2026年11月1日にデプロイ。実行ユーザーは所有者、アクセスは全員です。
GETは公開用30レシピ・栄養文・お知らせだけを返し、POSTは記録の追加・編集・削除を受け付けます。
入力者、確認者、DriveID、行動ログ、教材、クイズ等の非公開管理情報は返しません。
コード内の接続先シートIDは保護者版コピーに固定しています。

APIのURLは `config.js` に設定しています。
コピーされた写真公開処理・content.json公開処理の保存先も新リポジトリへ修正しました。
旧公開関数は保護者版の公開処理に転送するよう変更しています。

日常のシート編集の反映にGitHubトークンは不要です。
content.json自体をシートから更新する任意の手動公開機能は、コピー側の `GITHUB_TOKEN` 設定を使います。
リポジトリに保存した `GoogleAppsScript_保護者版公開.gs` は、`PARENTS_GITHUB_TOKEN` を使う別の補助処理で、
現在のAPI連携には不要です。必要な場合だけコピー側へ追加し、新リポジトリに限定した権限で設定します。
トークンはコード、config.js、チャットへ書きません。

## 試験と保護

- 30レシピの材料・手順・写真参照・栄養値等を元データと比較。
- 端末内での同日・同料理の複数登録、摂取量0、編集・削除、保存失敗、元保存領域の非変更を検証。
- 受信処理の入力検証、非公開情報の除外、重複・古い変更の拒否、固定シート接続を自動検証。
- 実APIで0の登録、重複登録、編集、削除、古い再送、削除再送を検証。
- 接続試験の参加者IDは `P-TEST-` から始め、「保護者記録_接続テスト」へ分離。
- 2026年11月1日、公開アプリでの削除・再読み込み後の状態・送信完了について、利用者から確認済みの回答を受領。

元の接続設定は `original-config.js.txt` に参照用として保存しています。
Service Workerはコピー先のパスに限定し、元アプリのキャッシュを削除しません。
